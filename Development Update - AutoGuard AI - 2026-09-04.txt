1. EXECUTIVE SUMMARY & SYSTEM OVERVIEW
--------------------------------------------------------------------------------
AutoGuard AI is a high-performance, dual-capability automotive intelligence platform that unifies AI-driven Vehicle Forensic Inspection (GDVF - Global Director of Vehicle Forensics) with an in-motion Tactical GPS Co-Pilot (Global Guardian).

The platform operates on a resilient Hybrid Local/Cloud AI paradigm. It is capable of running 100% offline and air-gapped on local hardware utilizing Ollama (running multimodal vision models such as Moondream and high-reasoning text models such as Llama 3.2 3B and Qwen 2.5 1.5B) while supporting seamless, automated failover to Google Gemini Cloud APIs (Gemini 2.5 Pro Preview and Gemini 2.0 Flash Live).

Key System Highlights:
• 6-Phase Standardized Forensic Capture: Front/Bumper, Side/Jambs, Engine Bay, Undercarriage/Rails, Interior/Airbags, and Acoustic Engine Diagnostics.
• Browser-Native Acoustic Spectrum Analysis: Real-time 20Hz-20kHz FFT frequency decomposition with 20Hz Biquad highpass DSP filtering for mechanical anomaly detection (engine knock, valve lifter ticks, belt squeals, wheel bearing whines).
• Tactical Weather Shield & Grip Index: Real-time Open-Meteo telemetry integration mapping WMO weather codes and precipitation intensity into dynamic tire-to-road friction coefficients (15%-99%) with speed caps.
• Enterprise Persistence: Browser-native IndexedDB database ('AutoGuardDB', store 'inspection_reports') providing unlimited offline storage for high-resolution photo evidence, paired with optional Firebase cloud sync.
• Dual-Audience Reporting: Instant switching between Forensic Master Technical Reports (multi-tier cost estimates: DIY/Independent/Dealer) and Customer Transparency Certificates (plain English summaries, 5-star ratings, sanitized PDF and JSON export).

4. SECURITY & RISK REGISTER
--------------------------------------------------------------------------------
• Security Controls Implemented:
  1. HTML Sanitization: Added escapeHtml() in ReportView.tsx to prevent DOM/XSS injection when generating PDF print windows.
  2. Local-First Privacy: Zero telemetry or vehicle images are sent over external networks when Local AI (Ollama) is active.
  3. Safe Secret Handling: Firebase and Gemini services degrade gracefully when API keys are absent, preventing runtime application crashes.

• Risk Register:
  [RISK-01] LocalStorage 5MB Quota Overflow -> RESOLVED: Migrated to native IndexedDB storage engine.
  [RISK-02] Microphone Handling Rumble Distorting Anomaly Spectrum -> RESOLVED: Added 20Hz Biquad highpass filter.
  [RISK-03] Client-side Exposure of VITE_GEMINI_API_KEY in Public Deployments -> MITIGATION PLANNED: Implement optional backend edge proxy (Fastify / Cloudflare Worker).
